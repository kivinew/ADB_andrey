# AndroidManager-CSharp

Кроссплатформенное десктопное приложение на **C# (.NET 10)** и **Avalonia UI** для управления Android-устройствами через **ADB**.

## Основные возможности

- **Подключение** — выбор подключённых по USB устройств, беспроводное подключение по IP:порт, сопряжение (ADB Pair), история подключений и избранное.
- **Приложения** — просмотр установленных пакетов с фильтрацией, запуск, остановка, очистка данных, отключение/включение и удаление.
- **Процессы** — мониторинг активных процессов на устройстве.
- **Консоль** — выполнение произвольных ADB/shell-команд с быстрыми кнопками и выводом результата.
- **Карточки** — наглядные метрики устройства в реальном времени (с графиками-спарклайнами).
- **Действия** — быстрые действия и кастомные команды для устройства.
- **Скрипты** — добавление и запуск пользовательских скриптов (`.py`, `.ps1`, `.sh`, `.bat`, `.cmd`) с передачей `ANDROID_SERIAL` и выводом `stdout`/`stderr`.
- **Логи** — просмотр системных логов и событий приложения.
- **Настройки** — выбор темы, шрифта, размеров текста, лимита истории и других параметров.

## Структура решения

- `AndroidManager/` — графический интерфейс на Avalonia UI (`Views/`, `Controls/`, `Services/`).
- `AndroidManager.Core/` — ядро работы с ADB, парсинг, модели устройств и настройки.
- `AndroidManager.Core.Tests/` — модульные тесты ядра.
- `AndroidManager.SelfCheck/` — консольная утилита самопроверки.

## Требования

- [.NET 10 SDK](https://dotnet.microsoft.com/)
- Установленный `adb` (Android Platform Tools) в `PATH`

## Сборка и запуск

```bash
# Сборка решения
dotnet build

# Запуск приложения
dotnet run --project AndroidManager

# Запуск тестов
dotnet test
```
