# Android Manager — История версий

## v1.5.0 (текущая разработка)
- Переименование: «КЭС ТВ-Менеджер» → **Android manager**
- Путь установки: `Android-manager` (вместо `KES-TV-Manager`)
- Все упоминания старого бренда заменены на **Android manager**
- Вкладка «Консоль»:
  - Кнопка **«Открыть окно»** → запускает системный `adb shell` в отдельном окне
  - Кнопка **«Kill PID»** в строке ввода → убивает процесс по PID из буфера обмена
  - Стриминг вывода (`logcat`, `top`, `dmesg -w`, `watch`, `ping`, `tail -f`) без зависаний UI
  - Автоопределение стриминговых команд (исключены `logcat -d/-c/-t`)
  - Кнопка «■ Стоп» для прерывания стриминга
- Пульт (вкладка «Инструменты»):
  - Исправлены кликабельные кнопки (инициализация canvas, фокус)
  - Добавлен тип кнопки **`pc`** — выполнение команд на ПК с подстановками `{clipboard}`, `{serial}`
  - Добавлен тип кнопки **`shell`** с подстановкой `{clipboard}` для консольных кнопок
  - Кнопка **«Вкл. на устройстве»** для включения «Показывать касания» через `settings put system show_touches 1`
- Скрипты (вкладка «Скрипты»):
  - Исправлен `import adb` — внедрение модуля через `sys.modules` с привязанной `shell()`
  - Скрипт `tvdiag_report.py` работает без ошибок `ModuleNotFoundError`
- Установщик:
  - Контекстное меню в логе (Копировать / Копировать всё)
  - Окно установки показывает «Android manager»
- Кнопка «Сопрячь» для ADB pairing по Wi-Fi (Android 11+)
